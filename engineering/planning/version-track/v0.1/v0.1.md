# v0.1 — Foundations and themed components

*Last updated: 2026-11-10*

**Status:** 🚧 In Progress · **Type:** Feature · **Started:** 2026-11-09 · **Completed:** —

### Iteration 1 — Repository

- [x] Ability to add the package by git URL and pin a `0.0.y` tag
- [x] Ability to get a tested `0.0.y` tag from CI on each push to main

### Iteration 2 — Theme

- [x] Ability to restyle every component by supplying one theme
- [x] Ability to brand a theme by editing its tokens
- [x] Ability to resolve light and dark from the same tokens
- [x] Ability to check a theme's WCAG AA contrast

### Iteration 3 — Components

- [x] Ability to style a button primary, secondary, destructive or ghost
- [x] Ability to run an async action from a self-busy button
- [x] Ability to group content in an outline, elevated or soft card
- [x] Ability to enter text with a label, helper line and error line
- [x] Ability to toggle a setting from a list row
- [x] Ability to group rows into a titled list section
- [x] Ability to head a sheet with a title and a close button
- [x] Ability to show queued toasts by tone
- [x] Ability to show an empty state with actions
- [x] Ability to show skeletons while content loads

### Iteration 4 — Foundations

- [x] Ability to read the environment and API base URL from the build
- [x] Ability to call a be sdk API and get a typed result
- [x] Ability to read field errors from a validation failure
- [x] Ability to log by category over the unified log

### Iteration 5 — Showcase

- [x] Ability to browse every component under a theme switch

### Iteration 6 — Components II

- [x] Ability to pass runtime-resolved `String` titles to every component
- [x] Ability to choose a setting from a few options in a list row
- [x] Ability to switch between a few values with a segmented control
- [x] Ability to mark a status or category with a badge or status pill
- [x] Ability to show an inline banner with an action and a dismiss button
- [x] Ability to show determinate and indeterminate progress
- [x] Ability to show a person's picture or initials
- [x] Ability to inset a list section's separators to the row titles
